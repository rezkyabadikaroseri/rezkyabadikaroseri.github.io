# CV. Rezky Abadi Karoseri

Situs katalog harga dan presentasi produk trailer container 20 & 40 feet.

- Katalog harga: https://rezkyabadikaroseri.github.io/
- Presentasi: https://rezkyabadikaroseri.github.io/presentasi.html

## Mengubah harga katalog

Buka `data.js`, ganti angka di bagian `harga` (tanpa titik), lalu simpan.
Harga di slide presentasi ada di `presentasi.html`, bagian `Daftar harga per unit`.

## Menjalankan presentasi

| Tombol | Fungsi |
| --- | --- |
| → / spasi / PageDown | Slide berikutnya (bisa pakai clicker presentasi) |
| ← / PageUp | Slide sebelumnya |
| F | Layar penuh |
| G | Lihat semua slide |
| N | Catatan pembicara |
| P | Mode presenter (jendela baru: catatan, slide berikutnya, timer) |
| K | Putar / jeda video di slide aktif |

Video baru diputar saat tombol **Putar video** diklik. Untuk menyimpan sebagai PDF, klik ikon printer lalu pilih "Simpan sebagai PDF".

Semua file sengaja diletakkan di folder utama agar mudah diunggah lewat HP.
